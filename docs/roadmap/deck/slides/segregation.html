A2A

The cut: a skill is procedural knowledge bound to a role, how the job gets done. MCP is the trust-boundary protocol for everything outside the agent process: context in on the read side, actions out on the write side. On the write side the backends are the platform's own: OpenShift ships MCP backends for platform operations, and CNF vendors are being onboarded to provide backends for the telco application layer; the shipped courses run stand-ins for both. A2A is role delegation. The two kinds get two governance regimes: skills as content (review, version, judge), capabilities at runtime (identity, rate, catalog). The whole stack sits on one evidence rail.
